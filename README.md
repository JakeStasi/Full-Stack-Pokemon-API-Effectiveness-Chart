The **Pokémon Collection App** is a full-stack web application that allows users to search for Pokémon using the PokéAPI and save selected Pokémon to a PostgreSQL database. The app retrieves Pokémon information such as names, images, types, abilities, and descriptions, then stores the selected data so users can build and manage their own saved Pokémon collection.

This project was built to practice working with external APIs, server-side routing, PostgreSQL databases, and full-stack application structure. The backend uses **Node.js** and **Express** to handle RESTful routes for searching, adding, viewing, and deleting Pokémon records. The frontend uses **HTML, CSS, and JavaScript** to provide a simple interface for users to interact with the app.

## Features

* Search Pokémon by name using the PokéAPI
* Retrieve Pokémon images, types, abilities, and descriptions
* Save selected Pokémon to a PostgreSQL database
* View a persistent collection of saved Pokémon
* Prevent duplicate Pokémon entries with server-side checks
* Delete Pokémon from the saved collection
* Built RESTful Express routes for managing Pokémon data

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Node.js, Express.js
* **Database:** PostgreSQL
* **API:** PokéAPI

## What I Learned

Through this project, I practiced integrating a third-party API with a backend server, parsing JSON responses, designing database queries, and creating RESTful routes. I also learned how to persist external API data in PostgreSQL and manage user interactions through a full-stack web application.
